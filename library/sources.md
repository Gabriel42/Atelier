# Free asset sources

Places to find free assets for any game. Licenses change and pages move: **open the
asset page and read its license before using anything.** The "License" column is the
usual license for the site, not a promise for every file on it.

## Art (2D and 3D)

| Source | What it has | Usual license | Link |
|---|---|---|---|
| Kenney | Sprites, tiles, UI, icons, 3D models, sounds. Huge and consistent | CC0 (public domain) | https://kenney.nl |
| Quaternius | Low-poly 3D models, characters, animations | CC0 | https://quaternius.com |
| Poly Haven | 3D models, HDRIs, textures | CC0 | https://polyhaven.com |
| ambientCG | PBR textures and materials | CC0 | https://ambientcg.com |
| OpenGameArt | Mixed art, music and sound from many authors | Varies per asset (CC0, CC-BY, GPL...) | https://opengameart.org |
| Game-icons.net | Thousands of game icons | CC BY 3.0 (credit needed) | https://game-icons.net |
| Lospec | Pixel-art palettes and tutorials | Varies | https://lospec.com |
